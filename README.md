# Предсказание цены аренды квартиры: линейные модели с нуля

Учебный проект по курсу ML. Задача регрессии: предсказать цену аренды
по числу ванных и спален и по признакам объявления (`features`).
Линейные модели и нормализаторы реализованы вручную на NumPy
и сверены с реализациями из scikit-learn.

## Что сделано
- Теория: вывод нормальных уравнений, L1/L2-регуляризация,
  почему L1 отбирает признаки, как сделать линейную модель нелинейной
- Подготовка данных:
  - очистка текстового списка `features`
  - бинарные признаки по топ-20 самым частым значениям
  - удаление выбросов по цене (квантили 1%–99%) и по `bathrooms > 20`
- Собственная `LinearRegression`: аналитическое решение,
  batch GD, mini-batch SGD и SGD (bs=1)
- Собственная `RegularizedRegression`: Ridge (замкнутая форма),
  Lasso и ElasticNet (координатный спуск, soft-thresholding)
- Собственные `MyMinMaxScaler` и `MyStandardScaler`.
  Результаты совпадают со sklearn (`allclose = True`)
- Сравнение моделей без нормализации, с MinMax и со Standard
- Полиномиальные признаки степени 10 (демонстрация переобучения)
- Наивные baseline-модели (среднее и медиана)

## Результаты (тестовая выборка)

| Модель | MAE | RMSE | R² |
|---|---|---|---|
| Naive mean | 1137.8 | 1590.4 | 0.00 |
| Linear (normal), свои = sklearn | 714.7 | 1043.5 | 0.570 |
| Mini-batch SGD (bs=64) | 718.8 | 1047.7 | 0.566 |
| SGD (bs=1) | 825.0 | 1154.6 | 0.473 |
| ElasticNet + StandardScaler | 714.5 | 1043.4 | 0.570 |
| Polynomial (deg=10), Linreg | 2.7e7 | 5.5e9 | −1.2e13 |

## Выводы
- Свои реализации дают те же метрики, что и sklearn
  (различия в 6-м знаке и дальше).
- Для бинарных признаков нормализация почти не влияет на качество.
  Исключение: ElasticNet с MinMax ухудшается (R² 0.49), потому что
  штраф зависит от масштаба признаков.
- Полином степени 10 на двух дискретных признаках сильно переобучается.
  Регуляризация смягчает проблему, но не устраняет её.
- R² ≈ 0.57 против 0 у baseline: линейная модель на этих признаках
  объясняет примерно 57% дисперсии цены.
